# forge 配布物の文書型と役割

forge の**開発ルール**。`plugins/forge/` 配下の規範文書について、どの種類のファイルに何を書くかを定める。配布物ではなく、この repo の開発者が遵守する。

**基本形を定めるものであり、すべての文書がこのいずれかに当てはまる必要はない。** 複数の関心事を扱う文書や、どれにも当てはまらない文書は存在してよい。

---

## 基本形

| ファイル種別                           | 書くもの                                                                                                | 書かないもの                      |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------- | --------------------------------- |
| `*_format.md`                          | 成果物の構造・テンプレート・識別子や命名の体系                                                          | 原則・判断基準・実行手順          |
| `*_principles_spec.md`                 | 原則・規範・禁止事項・判断基準・重大度カタログ                                                          | テンプレート・実行手順            |
| `SKILL.md` および SKILL が読む手順文書 | フロー・Phase・実行手順・分岐                                                                           | 規範本体（principles を参照する） |
| `criteria/review_criteria_*.md`        | 照合順序、委譲先の一覧、レビュー観点の切り分け、所見の扱い（`fix` / `create_issue` / `skip`）の採用条件 | 規範本体の再掲                    |

## 原則

- **接尾辞を持つ文書は、その基本形に従う**。`*_format.md` に原則を、`*_principles_spec.md` にテンプレートを書かない
- **1 文書 1 種類を基本とする**。規範と手順を混ぜると、手順を知りたい者に規範を読ませ、規範を知りたい者に手順を読ませることになる
- **規範の本文は 1 か所**。SKILL や criteria は規範を再掲せず参照する
