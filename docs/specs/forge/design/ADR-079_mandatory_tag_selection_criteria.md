# ADR-079 規範タグの選別は罠の機構で判定し、事故の実績・記録・確率を成立条件にしない

> **本文書のスコープ**
>
> - **定めること**: `[MANDATORY]` 等の規範タグを維持・付与する判定における証拠の扱い（機構ベース判定）と、タグ周辺の本文に置く理由の形
> - **定めないこと**: 基準 A〜E の本文・タグの配置規則・格下げ階段そのもの（[document_style_guide.md](../../../../plugins/forge/docs/document_style_guide.md) §1.2 が定める）。個別文書のどのタグを残すかの各論
> - **document_style_guide.md との関係**: 同文書 §1.2 の運用解釈を確定する決定であり、置き換えない

## 1. コンテキスト

規範タグは「希少だから効く」信号であり、基準 A〜E に該当するものだけに付ける（document_style_guide.md §1.2）。しかし基準 E の文言「AI が高確率で間違える既知の罠（過去にインシデント化した規約違反…）」は、**罠の実在をどこで確認するか**（証拠の所在）を規定していない。このため選別作業では次の解釈揺れが生じる:

- 事故の叙述が本文にあるタグを「実績あり」として優先的に残す
- 事故の記録が ADR にあるかどうかで判定する
- 発生回数・確率で重み付けする

いずれも一見合理的だが、規範文書へ事故叙述を書き足す誘因・記録の所在と規範の効力の癒着・保守されない帳簿という別の問題を生む。タグの過剰付与（配布物で 300 箇所超）の選別・低減に着手するにあたり、判定の証拠の扱いを確定する必要がある。

## 2. 決定

### 2.1 基準 E は罠の機構で判定する

E の判定は「**罠の機構が現在も成立しているか**」で行う。機構とは、間違いが構造的に起きやすい形（散文の網羅に依存する手順・推測で埋めたくなる欠落・混同しやすい隣接概念）と、起きたときの性質（露見が遅い・不可逆）の組である。判定は当該文書と対象を読めばその場で検証できることを要件とし、事故の帳簿・外部記録の参照を前提にしない。

### 2.2 証拠の所在をタグの成立条件にしない

規範文書本文の事故叙述の有無・ADR 等への事故記録の有無を、タグ維持の判定材料にしない。実績は機構の実在が疑わしいときの補強証拠にとどめる。機構が成立していれば事故 1 度（または未発生）でもタグは正当であり、機構が消えていれば何度起きていてもタグは見直し対象である。

### 2.3 タグ周辺の本文は「規則＋機構の理由」に限る

タグを付けた規範の本文には、規則と、それを守らせる機構の理由（現在形・1〜2 文）だけを書く。経緯・回数・「かつて〜だった」という叙述を規範文書に置かない。事実の履歴は git が持ち、決定と棄却理由は ADR が持つ。

## 3. 検討した代替案

| 代替案                                           | 棄却理由                                                                                                                                                                                                                       |
| ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 本文に事故実績が書かれていることを維持根拠にする | タグを守るために事故叙述を書き足す誘因が生まれ、規範文書が決定記録化する（タグ過剰と同型の腐敗）。叙述の有無は編集の巡り合わせで決まる属性であり、規範の重要度と独立である。前提「実績の明記＝重要」が成立しない               |
| ADR に事故記録があることを維持根拠にする         | ADR が持つのは決定と、将来の提案の語彙で書いた棄却理由であり、経緯・回数の帳簿ではない。記録の所在を規範の効力条件にすると、記録の移動・欠落でタグの正当性が変わる転倒が起きる。前提「ADR＝事故台帳」が ADR の運用原則に反する |
| 発生確率・回数で重み付けする                     | 判定のために事故を数える帳簿が必要になり、その帳簿は保守されない。回数は将来の判断を変えない——機構が成立していれば 1 度でも正当、機構が消えれば何度でも見直し対象。前提「頻度＝重要度」が成立しない                            |

## 4. 影響

- **得るもの**: タグ判定が文書と対象の読解だけで完結する（帳簿・外部記録が不要）。規範文書が簡潔に保たれ、事故のたびに禁止文と叙述が積み上がる経路を塞ぐ。タグ選別・低減の展開作業に一貫した判定基準を与える
- **失うもの・制約**: 「実際に起きた」という一見客観的な根拠を判定に使えない。判定品質は機構の言語化能力に依存し、機構をまだ言語化できていない罠は拾えない
- **新たに生じる運用**: 規範文書の理由文に経緯叙述を見つけたら、機構の理由 1〜2 文へ圧縮する改稿対象とみなす（履歴として残す価値がある判断は ADR へ移す）
