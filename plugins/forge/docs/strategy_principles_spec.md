# 実装戦略書 作成原則

プロジェクト固有のルールがない場合に参照する汎用原則。
プロジェクト固有のルールがある場合はそちらを優先すること。

策定手順（実装戦略 agent への作業指示）は [strategy_formulation_spec.md](strategy_formulation_spec.md) を参照。

---

## 実装戦略書の定義

- **責務**: 実装アプローチの選択、フェーズ分割、各フェーズの検証ポイント、リスクと対策。差分開発では、旧仕様と相反する実装をどの順序で処理していくか
- **書かないもの**: 構造の設計（設計書の責務）／個々のタスクの実行単位（計画書の責務）
- **存在期間**: 一時。計画書と同じライフサイクルで扱い、全タスク完了時に計画書とともに存廃を利用者が選択する
- **正式名称**: 実装戦略書。ファイルは `{feature}_strategy.md`
