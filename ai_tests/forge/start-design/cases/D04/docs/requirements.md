# FOO-REQ-031 在庫不足の通知 要件定義書

## 1. 概要

品目の在庫数が、品目ごとに決めた下限を下回ったとき、その品目の担当者へ直ちに知らせる。

## 2. 用語

| 用語   | 定義                                     |
| ------ | ---------------------------------------- |
| 品目   | 在庫を管理する単位。品目コードで識別する |
| 在庫数 | 品目ごとの現在の数量                     |
| 下限   | 品目ごとに決める在庫数の基準値           |
| 担当者 | 品目ごとに決められた、補充を判断する人   |

## 3. 機能要件

### FNC-001: 下限の設定

管理者が品目の下限を設定したとき、システムはその下限を記録すること。下限が設定されていない品目は、通知の対象にしない。

### FNC-002: 在庫不足の通知

在庫数が更新されて下限を下回ったとき、システムはその時点で直ちに、品目の担当者へ通知すること。通知には品目コード・在庫数・下限を含める。

### FNC-003: 重複の抑止

すでに下限を下回っている品目の在庫数がさらに減っても、再び通知しないこと。在庫数が下限以上に戻ったあと、再び下回ったときは通知する。

## 4. 非機能要件

該当なし。

## 5. 未確定事項

該当なし。
