# FOO-DES-001 在庫管理 設計書

## 1. 概要

[FOO-REQ-001](FOO-REQ-001_inventory.md) の設計。

## 2. 共有データ

| データ名     | 意味                   | 正本     | 書き手   | 読み手               |
| ------------ | ---------------------- | -------- | -------- | -------------------- |
| 在庫レコード | 品目コードと在庫数の組 | 在庫台帳 | 在庫台帳 | 入出庫受付、在庫照会 |

## 3. 契約

### 在庫台帳

`在庫を更新する(品目コード, 増減数)`

| 項目       | 内容                                                           |
| ---------- | -------------------------------------------------------------- |
| 呼び出し元 | 入出庫受付                                                     |
| 事前条件   | 品目コードが登録済み。減らす場合は在庫数が足りる               |
| 事後条件   | 在庫レコードの在庫数だけが変わる。他の部品へは何も知らせない   |
| 失敗時     | 在庫数が足りなければ「在庫不足」を返し、在庫レコードは変えない |

## 4. 実装

`foo/inventory.py` の `update_stock`。
