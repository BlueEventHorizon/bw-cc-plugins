# BAR-REQ-010 週次まとめ通知 要件定義書

## 1. 概要

Bar タスク管理の利用チームに、前の週に完了したタスクの件数と一覧を、メールで知らせる。

## 2. 用語

| 用語       | 定義                                                                       |
| ---------- | -------------------------------------------------------------------------- |
| タスク記録 | Bar タスク管理が保持するタスクの一覧。各タスクは名前・担当者・完了日を持つ |
| 週次まとめ | 前の週（月曜〜日曜）に完了したタスクの件数と一覧                           |
| 通知先     | チームごとに設定された、メールの宛先の一覧                                 |

## 3. 機能要件

### FNC-001: 週次まとめの作成

運用者が通知を実行したとき、システムはタスク記録から前の週に完了したタスクを取り出し、週次まとめを作ること。

### FNC-002: メールでの通知

システムは、週次まとめを本文にしたメールを、通知先へ送ること。件名には対象の週の期間を含める。

### FNC-003: 完了タスクが無い場合

もし前の週に完了したタスクが無かったら、システムは「完了したタスクはありません」と書いたメールを送ること。

### FNC-004: 送信の失敗

もしメールの送信に失敗したら、システムは再試行せず、失敗したことを記録して、失敗として終了すること。
