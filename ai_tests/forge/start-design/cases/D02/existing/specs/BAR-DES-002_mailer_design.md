# BAR-DES-002 メール送信 設計書

## 1. 概要

Bar タスク管理の各機能が共通に使う、メール送信の部品。

## 2. 契約

`send_mail(to, subject, body)`

| 項目     | 内容                                                         |
| -------- | ------------------------------------------------------------ |
| 入力     | 宛先の一覧（文字列のリスト）、件名、本文（プレーンテキスト） |
| 出力     | なし                                                         |
| 事前条件 | 宛先の一覧が 1 件以上ある                                    |
| 事後条件 | すべての宛先へメールが送られている                           |
| 失敗時   | `MailError` を送出する。再試行はしない                       |

## 3. 実装

`bar/mailer.py`。SMTP の接続先は設定ファイルから読む。
