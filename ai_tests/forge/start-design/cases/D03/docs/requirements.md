# FOO-REQ-020 売上レポートの JSON 出力 要件定義書

## 1. 概要

外部の分析サービスに渡すため、店舗ごとの売上合計を JSON で出力する。

## 2. 用語

| 用語         | 定義                                                                 |
| ------------ | -------------------------------------------------------------------- |
| 売上記録     | Foo 売上管理が保持する、1 件の販売ごとの記録。店舗・日付・金額を持つ |
| 集計期間     | レポートの対象にする日付の範囲                                       |
| 売上レポート | 集計期間の店舗ごとの売上合計                                         |

## 3. 機能要件

### FNC-001: JSON での出力

運用者が集計期間を指定して出力を実行したとき、システムは集計期間の売上レポートを JSON ファイルに出力すること。

JSON には、集計期間（開始日・終了日）、店舗ごとの売上合計、レポートを作った日時を含める。

### FNC-002: 売上が無い店舗

集計期間に売上が無い店舗は、売上合計 0 として含めること。

### FNC-003: 集計期間の誤り

もし集計期間の開始日が終了日より後なら、システムは出力せず、誤りを運用者に示すこと。
