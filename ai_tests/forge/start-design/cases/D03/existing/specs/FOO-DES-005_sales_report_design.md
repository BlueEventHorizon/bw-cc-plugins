# FOO-DES-005 売上レポート（CSV）設計書

## 1. 概要

経理担当者向けに、店舗ごとの売上合計を CSV で出力する。

## 2. 構成

| 部品                                   | 責務                                               |
| -------------------------------------- | -------------------------------------------------- |
| `foo/sales.py` の `aggregate_by_store` | 売上記録と集計期間から、店舗ごとの売上合計を求める |
| `foo/report_writer.py` の `write_csv`  | 店舗ごとの売上合計を、経理の書式の CSV に書く      |

## 3. 契約

`aggregate_by_store(records, start, end) -> dict[str, int]`

- 入力: 売上記録の一覧、集計期間の開始日・終了日
- 出力: 店舗名から売上合計への対応。売上の無い店舗も 0 で含める（店舗の一覧は店舗マスタから得る）
- 失敗時: 開始日が終了日より後なら `ValueError`

`write_csv(totals, path)`

- 入力: 店舗名から売上合計への対応、出力先
- 出力: 列が「店舗コード」「店舗名」「売上（税抜・千円単位）」の CSV。経理の書式に固定されている
