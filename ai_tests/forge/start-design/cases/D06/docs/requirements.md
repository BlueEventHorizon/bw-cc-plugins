# BAR-REQ-050 Bar 設定整形 要件定義書

## 1. 概要

ディレクトリ内の設定ファイル（YAML）を、決まった書式に整える。

## 2. 用語

| 用語             | 定義                                                         |
| ---------------- | ------------------------------------------------------------ |
| 設定ファイル     | 拡張子が `.yaml` のファイル                                  |
| 対象ディレクトリ | 利用者が指定するディレクトリ。配下の設定ファイルを整形する   |
| 決まった書式     | キーを辞書順に並べ、字下げを空白 2 個にした書き方            |
| 確認モード       | ファイルを書き換えず、整形が必要なファイルを示すだけの動き方 |

## 3. 機能要件

### FNC-001: 整形

利用者が対象ディレクトリを指定して実行したとき、ツールは配下のすべての設定ファイルを決まった書式に書き直すこと。

### FNC-002: 読めないファイル

もし設定ファイルが YAML として読めなかったら、ツールはそのファイルを書き換えず、ファイル名と理由を示すこと。ほかのファイルの整形は続ける。

### FNC-003: 確認モード

確認モードが指定された場合、ツールはどのファイルも書き換えず、整形が必要なファイルの一覧を示すこと。

### FNC-004: 書き込みの範囲

ツールは、対象ディレクトリの外のファイルを書き換えないこと。

### FNC-005: 意味の保存

整形の前後で、設定の意味（キーと値の対応）を変えないこと。

## 4. 非機能要件

### NFR-001: ネットワーク

ツールは、外部のネットワークに接続しないこと。
