# HOGE-REQ-040 共有リンクでの閲覧 要件定義書

## 1. 概要

文書の所有者が共有リンクを発行し、リンクを知っている人が文書を閲覧できるようにする。

## 2. 用語

| 用語       | 定義                                                   |
| ---------- | ------------------------------------------------------ |
| 文書       | Hoge 文書共有が保管するファイル                        |
| 所有者     | 文書をアップロードした利用者                           |
| 共有リンク | 文書ごとに発行する URL。知っている人は誰でも閲覧できる |
| 有効期限   | 共有リンクが使える期限                                 |

## 3. 機能要件

### FNC-001: 共有リンクの発行

所有者が文書と有効期限を指定して共有リンクの発行を求めたとき、システムは共有リンクを発行して所有者に示すこと。

### FNC-002: 共有リンクでの閲覧

共有リンクにアクセスしたとき、システムはその文書を表示すること。アカウントを持たない人も閲覧できる。

### FNC-003: 期限切れ

もし共有リンクの有効期限が過ぎていたら、システムは文書を表示せず、期限切れであることを示すこと。

### FNC-004: 共有リンクの取り消し

所有者が共有リンクを取り消したとき、システムはそのリンクでの閲覧をできなくすること。

## 4. 非機能要件

該当なし。

## 5. 未確定事項
