# D05

既存のシステム「Hoge 文書共有」に、共有リンクで文書を閲覧できる機能を追加する設計を行う。

入力の要件定義書には `feature_type: temporary-feature` frontmatter が無い（要件定義の段階では、既存の要件と重ならないと判断された）。

## 読む文書

| 文書                   | 読んでよい時点      |
| ---------------------- | ------------------- |
| `docs/requirements.md` | 最初から            |
| `existing/specs/`      | Phase 3（照合）から |

`docs/rules.md` と `existing/code/` は無い。
