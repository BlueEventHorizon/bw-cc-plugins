# HOGE-REQ-002 アクセス制御 要件定義書

## 1. 概要

Hoge 文書共有の文書を、許可された利用者だけが扱えるようにする。

## 2. 機能要件

### FNC-001: ログイン

利用者がアカウントとパスワードでログインしたとき、システムは認証済みのセッションを発行すること。

### FNC-002: 閲覧の前提

文書の閲覧・ダウンロードは、すべて認証済みのセッションを前提とすること。認証済みのセッションが無いアクセスには、文書を返さない。

### FNC-003: 閲覧の権限

認証済みの利用者は、所有者から閲覧を許可された文書だけを閲覧できること。

## 3. 非機能要件

### NFR-001: 監査

文書の閲覧は、閲覧した利用者のアカウントとともに記録すること。
