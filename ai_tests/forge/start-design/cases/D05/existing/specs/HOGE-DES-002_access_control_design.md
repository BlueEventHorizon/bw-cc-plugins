# HOGE-DES-002 アクセス制御 設計書

## 1. 概要

[HOGE-REQ-002](HOGE-REQ-002_access_control.md) の設計。

## 2. 契約

### 文書配信

`文書を返す(セッション, 文書ID)`

| 項目     | 内容                                                                 |
| -------- | -------------------------------------------------------------------- |
| 事前条件 | セッションが認証済みで、利用者がその文書の閲覧を許可されている       |
| 事後条件 | 文書の内容を返し、閲覧をアカウントとともに監査記録に残す             |
| 失敗時   | 認証済みでない・許可が無い場合は、文書を返さず「アクセス拒否」を返す |
