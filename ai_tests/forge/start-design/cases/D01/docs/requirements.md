# HOGE-REQ-001 Hoge 日報集計 要件定義書

## 1. 概要

チームメンバーが日々書く日報ファイルを読み、プロジェクトごとの作業時間を集計して CSV に出力するコマンドラインツール。

## 2. 用語

| 用語         | 定義                                                            |
| ------------ | --------------------------------------------------------------- |
| 日報ファイル | メンバーが 1 日 1 つ書くテキストファイル。作業行の並びからなる  |
| 作業行       | 日報ファイルの 1 行。プロジェクト名と作業時間（時間単位）を持つ |
| 集計結果     | プロジェクトごとの作業時間の合計                                |
| 集計期間     | 集計の対象にする日付の範囲（開始日と終了日）                    |

## 3. 機能要件

### FNC-001: 日報ファイルの読み込み

利用者が日報ファイルを置いたディレクトリと集計期間を指定して実行したとき、ツールは集計期間に含まれる日付の日報ファイルをすべて読み込むこと。

### FNC-002: 作業時間の集計

ツールは、読み込んだ作業行をプロジェクトごとに集計し、作業時間の合計を求めること。

### FNC-003: CSV への出力

ツールは、集計結果を CSV ファイルに出力すること。列はプロジェクト名と合計作業時間とする。

### FNC-004: 書式の誤り

もし作業行の書式が誤っていたら、ツールはその行を集計に含めず、ファイル名と行番号を利用者に示すこと。処理は続ける。

### FNC-005: 対象が無い場合

もし集計期間に日報ファイルが 1 つも無かったら、ツールは CSV を出力せず、その旨を利用者に示すこと。
