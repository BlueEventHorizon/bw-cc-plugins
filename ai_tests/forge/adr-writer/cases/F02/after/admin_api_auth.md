# Bar 管理画面 API 認証設計（抜粋）

## 対象

Bar の管理画面が呼び出す API の認証方式を定める。

## 前提

- 管理画面は社内ネットワークの単一ドメインから使う
- 利用者は社内の運用担当者で、約 300 人
- API は複数台のサーバーで動き、ロードバランサの背後に置く

## 認証方式

- ログイン時にサーバー側でセッションを作り、セッション ID を Cookie に載せて返す
- セッションの状態は共有ストアに持ち、どのサーバーからも参照できる
- API は Cookie のセッション ID から利用者を識別する
- 自己完結型の署名付きトークンは使わない

## 失効

退職や権限剥奪が起きたとき、共有ストアのセッションを削除して該当する利用者の操作を止める。
