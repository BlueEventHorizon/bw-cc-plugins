# 計画書作成スキル 仕様（抜粋）

## 目的

設計書からタスクを抽出し、実装計画書を作成する。

## フロー

1. コンテキスト収集
2. 文書の読み込み
3. 実装戦略書の作成
4. 設計書からのタスク抽出・分割（戦略書に従う）
5. AI レビュー

## 実装戦略書

戦略書は、手順 3 で、設計書を読んだ AI が所定のパスへ書き出す。次の 5 セクションを持つ。

| セクション     | 記述内容                                                                                                        |
| -------------- | --------------------------------------------------------------------------------------------------------------- |
| アプローチ選択 | ボトムアップ・スケルトン先行・リスク駆動・フィーチャースライスの 4 戦略（または組み合わせ）から選び、根拠を書く |
| フェーズ分割   | 大枠の実装フェーズ（2〜4 フェーズ程度）を書く                                                                   |
| 検証ポイント   | 各フェーズ完了時に検証すべき事項を書く                                                                          |
| リスクと対策   | 技術的リスクと、どのフェーズで早期に潰すかの方針を書く                                                          |
| 既存資産の活用 | 設計書の「使用する既存コンポーネント」をどう組み込むかを書く                                                    |

## 戦略書とタスクの関係

- タスクは、戦略書のフェーズ分割に沿って並べる。
- 戦略書に書かれていないフェーズへ、タスクを割り当てない。
