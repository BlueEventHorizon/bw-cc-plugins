# Foo 判定フロー 設計書（抜粋）

## Phase 構成

Foo 判定フローは、Issue を受け取り、進め方（ワンショット実装 / 要件定義から開始）を判定する。次の Phase を番号順に実行する。

| Phase | 内容                                              |
| ----- | ------------------------------------------------- |
| 1     | Issue 本文の取得と種別の確認                      |
| 2     | 仕様書の検索                                      |
| 3     | ルール文書の検索                                  |
| 4     | 類似変更の調査                                    |
| 5     | 既存コードの調査                                  |
| 6     | 判定（判定1〜3）                                  |
| 6.5   | 追加開発規約の適用条件チェック                    |
| 7     | ルート確定（条件1〜3 を満たせばワンショット実装） |
| 8     | 結果の Issue への反映                             |

## 各判定の入力

- 判定1（要件確定性）: Issue 本文
- 判定2（影響範囲）: Phase 4〜5 の調査結果
- 判定3（リスクゲート条件1・2）: Issue 本文
- 条件3（既存実装との整合）: Phase 4〜5 の調査結果

## 実行方針

Phase 2〜5 の調査は、判定に入る前にすべて完了させる。調査結果は Phase 6 以降が参照する。
Phase 6.5 で適用条件が偽の場合は、追加開発規約に従わないルートへ進む。
