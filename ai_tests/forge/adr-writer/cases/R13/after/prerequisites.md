# 前提条件（抜粋）

Hoge を使うために、利用者の環境へ導入しておくものを示す。

## 外部依存

| 依存 | 要求する版 | 用途                 |
| ---- | ---------- | -------------------- |
| Bar  | 2.0.0 以上 | 文書の索引作成と検索 |

## Foo-index サーバ（任意）

- 文書検索の backend として使う場合に限り、導入する。
- 1.2.1 以上を要求する。それ未満の版では、未整備と退避を判別できない。

## 版の確認

- 導入済みの版は、起動時に確認する。要求する版を満たさない場合は、その旨を表示して処理を止める。
