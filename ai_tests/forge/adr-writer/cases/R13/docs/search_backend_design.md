# 文書検索 backend 設計（抜粋）

## backend

Hoge の文書検索は、Foo-index サーバを backend の 1 つとして使う。検索の前に、対象の ENTRY が検索可能かを確かめる。

## ENTRY の状態

| 状態     | 意味                                      | Hoge の動作                        |
| -------- | ----------------------------------------- | ---------------------------------- |
| 整備済み | 索引があり検索できる                      | そのまま検索する                   |
| 未整備   | ENTRY / series が存在しない               | 索引を作成してから検索する         |
| 退避     | ENTRY が退避（`archive_index`）されている | 索引を作成せず、復活操作を案内する |

未整備と退避を取り違えてはならない。両者を判別する手段が要る。

## error の判別

- 検索呼び出しが error を返したとき、未整備か退避かを error から判別する。
- 判別根拠は、Foo-index サーバ 1.2.0 に対する実測で得た、error の識別可能な要素として確定する。
- 退避状態の error は、`archive_index` が既存 ENTRY を壊すため、実測が済んでいない。実測の方法を、実装前に決める。

## 判別できない error

- 上記のいずれにも判別できない error は、障害として利用者へ報告する。
