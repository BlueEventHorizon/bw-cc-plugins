# Hoge レビュー 設計（抜粋）

## 位置づけ

Hoge メッセージ基盤の上に構築した応用機能。実装完了後に本体仕様へ統合され削除される一時文書である。

## 停止フック

停止フックは単一の Python スクリプトで実装する。Foo・Bar の双方の登録から呼ばれる。

差し戻しメッセージには、未読の本文に加えて「返信ヒント」（実行可能な返信コマンドの案内）を含める。
