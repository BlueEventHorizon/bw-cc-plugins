# 文書スタイルガイド（抜粋）

## 参照記法

参照元の位置によって、記法を使い分ける。

1. `manual/` 内部の文書から、同じ `manual/` の他文書を参照する場合: 相対パスで書く（例: `./flow_design.md`）
2. `manual/` の外側にある手順書・定義ファイルから `manual/` の文書を参照する場合: `${FOO_ROOT}/manual/<文書名>.md` 形式で書く

`${FOO_ROOT}` は Foo の配置先を指すプレースホルダであり、利用時に実パスへ置換される。シェル変数ではない。
手順書や定義ファイルは `manual/` の外にあり、相対パスでは参照先に届かないため、2. の記法を用いる。

## 語尾の長音

語尾の長音は省く（例: ディレクトリ、サーバ）。
