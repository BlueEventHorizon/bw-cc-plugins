# 実装規約（抜粋）

## スクリプト・文書の配置

- スクリプトと文書は、それを使うモジュールの直下（`modules/<module>/scripts/`、`modules/<module>/docs/`）に置く。
- あるモジュールは、他のモジュールの `scripts/` と `docs/` を参照しない。他モジュールの持ち物へ無断で依存すると、持ち主の改修で壊れる。
- 複数のモジュールが使うものは、共通の置き場（`shared/scripts/`、`shared/docs/`）へ昇格させる。昇格した資産は、使う側すべてがそこを参照する。
- 共通の置き場には、特定のモジュールにだけ意味のあるものを置かない。
- 同じ内容を複数モジュールへ複製して持たない。複製は片方だけ更新される乖離の原因になる。

## 命名

- スクリプトのファイル名は、動詞から始める（例: `parse_findings.py`）。
- 文書のファイル名は、内容を表す名詞句にする。
