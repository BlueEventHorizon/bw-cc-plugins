# R09 共有資産は共通の置き場へ昇格する

- 決定: 共有資産は配布物共通の置き場（`shared/scripts/`）へ昇格する。共通書式の解釈は `shared/scripts/` 配下へ昇格させ、本体・全バックエンドがそこを参照する。
- 文脈: 所見の共通書式の解釈規則は全バックエンド共通である。したがってその実装を特定バックエンドの `modules/<module>/scripts/` に置くと、他バックエンドから「他モジュールの持ち物への無断参照」になる（実装規約の「スクリプト・文書の配置」が禁じる）。
- 代替案: 共通書式の解釈を各バックエンドに複製する: 書式契約を全バックエンド共通に固定した別の決定と衝突する。片方だけ直して食い違う失敗が構造的に起きるため棄却。
