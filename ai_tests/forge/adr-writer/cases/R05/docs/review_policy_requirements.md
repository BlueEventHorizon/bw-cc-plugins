# レビュー方針 要件（抜粋）

## バックエンドとの入出力契約

レビュー本体は、バックエンドに対して次の要求を出す。

| 要求         | 入力                           | 出力             |
| ------------ | ------------------------------ | ---------------- |
| ラウンド実行 | 対象文書、規範、前ラウンド所見 | 所見と完了宣言行 |
| 終了通知     | ラウンド識別子                 | 受領の可否       |

## 再開モード

中断したレビューは、再開モードで続きから実行できる。再開時、本体は中断前のラウンドの状況をもとに次のラウンドを組み立てる。

## 備考

契約表の各要求は、全バックエンドが実装する。
