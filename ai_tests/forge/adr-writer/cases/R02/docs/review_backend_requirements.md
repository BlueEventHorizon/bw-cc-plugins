# レビューバックエンド 要件（抜粋）

## コンテキスト

レビューフローは、レビューを実行する主体（バックエンド）を `--backend` で交換可能にしている。利用できる実行主体はプロジェクトごとに異なるためである。

現行の唯一のバックエンドは Hoge レビューバックエンドである。これは次の構成の上に成り立つ。

- 人間が常駐させた Bar 端末セッションを相手にする
- 相手のターンを起こすため、停止フックと Piyo 多重化ツールによる起床を使う
- 往復の履歴は Hoge メッセージ基盤が保持する

これらを満たせないプロジェクトでは、レビューフロー全体が使えない。

## バックエンドの選択

- バックエンドは `--backend <名前>` で選択する
- 既定のバックエンドは設定ファイルで指定する
- 全バックエンド共通で、所見は自由記述 markdown + 重大度マーカー + 完了宣言行の書式で返す

## 仕様の置き場

バックエンドごとに、要件・設計を専用の仕様ディレクトリへ置く。
