# レビュー本体 手順書（抜粋）

## ラウンド

1. 対象を確定する。
2. バックエンドへ依頼を送る（`send_wait.py` が、送信・起床・待機を 1 回の呼び出しで行う）。
3. 返った所見を評価する。
4. 修正を実施する件数が 1 件以上なら、修正して次のラウンドへ進む。0 件なら、レビューを終える。

## 終了に関する記述

- 承認で終えるとき: 承認を利用者へ表示し、バックエンドへ終了通知を送る。
- ラウンド数の上限に達して打ち切るとき: 打ち切りを表示し、バックエンドへ終了通知を送る。
- バックエンドの失敗が確定したとき: 失敗を表示する。終了通知は送る。
- 利用者が段階的提示を中断したとき: 以降の修正を行わず、レビューを終える。
