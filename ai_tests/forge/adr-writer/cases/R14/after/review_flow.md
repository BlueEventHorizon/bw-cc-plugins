# レビュー本体 手順書（抜粋）

## ラウンド

1. 対象を確定する。
2. バックエンドへ依頼を送る（`send_wait.py` が、送信・起床・待機を 1 回の呼び出しで行う）。
3. 返った所見を評価する。
4. 終端でなければ、修正して次のラウンドへ進む。終端なら、終端処理へ進む。

終端かどうかは、手順 3 と、段階的提示の反映で、それぞれ 1 回だけ判定する。終端処理は、判定し直さない。

## 終端処理

レビューを終えるすべての経路は、この Step を通る。経路ごとに、次の表に従う。

| 経路         | 利用者への表示 | 終了通知 |
| ------------ | -------------- | -------- |
| 承認         | 承認           | 送る     |
| 打ち切り     | 打ち切り       | 送る     |
| 失敗確定     | 失敗           | 送る     |
| 利用者の中止 | 中止           | 送る     |

段階的提示を中断したときは、修正の件数によらず終端とし、この Step へ進む。
