# レビュー設計（抜粋）

## 本体とレビュアー

- 本体の実行主体は、対象の修正を含む、編集の能力を持つ。
- レビュアーは、本体から起動され、所見を返す。

## read-only の位置づけ

- レビュアーは read-only である。
- read-only は、レビュアー Agent の `tools` から編集手段を外すこと、`permissionMode` を `plan` にすること、役割定義で変更操作を禁じることで保証する。
- これらにより、レビュアーが成果物を変更しないことを、信用の根拠として本体が扱う。

## ラウンド

- 本体は、レビュアーを 1 ラウンドにつき 1 回起動する。
- 本体は、返った所見を評価し、必要な修正を行う。
