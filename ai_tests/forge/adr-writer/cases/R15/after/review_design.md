# レビュー設計（抜粋）

## 本体とレビュアー

- 本体の実行主体は、対象の修正を含む、編集の能力を持つ。
- レビュアーは、本体から起動され、所見を返す。

## read-only の位置づけ

- レビュアーは read-only であることを求められる。
- 役割定義による禁止、ツールの限定、実行モードの制限は維持する。これらは違反を防ぐ手段であり、担保ではない。
- read-only の担保を与える機構は置かない。
- 逸脱が起きた場合、その変更は git が差分として保持する。失われるのは、本体の修正とレビュアーの変更を切り分ける情報だけである。

## ラウンド

- 本体は、レビュアーを 1 ラウンドにつき 1 回起動する。
- 本体は、返った所見を評価し、必要な修正を行う。
