# Hoge メッセージ基盤 設計（抜粋）

## 構成

| 要素       | 内容                                             |
| ---------- | ------------------------------------------------ |
| 送信       | 宛先と本文を受け取り、履歴 DB へ記録する         |
| 受信箱     | 宛先ごとの未読を返す                             |
| 停止フック | 相手のターン終了時に未読を確認し、あれば差し戻す |

## 停止フック

Foo 用・Bar 用の 2 つの shell スクリプトで実装する。未読があるとき、差し戻しメッセージに未読の本文を含める。

## 汎用性

本基盤は、特定の用途に依存しないエージェント間メッセージングを提供する。
