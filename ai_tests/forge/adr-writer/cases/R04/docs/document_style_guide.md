# 文書スタイルガイド（抜粋）

## 参照記法

文書から他の文書を参照するときは、次の記法を用いる。

- 参照先は、常に `${FOO_ROOT}/manual/<文書名>.md` 形式のフルパスで書く
- 参照先の位置や参照元の位置によって記法を変えない

`${FOO_ROOT}` は Foo の配置先を指すプレースホルダであり、利用時に実パスへ置換される。

## リンクの書き方

- 本文の理解・検証に必要な参照だけを書く
- 表示名は文書の題名に合わせる

## 例

```markdown
詳細は [判定フロー](${FOO_ROOT}/manual/flow_design.md) を参照する。
```

## 語尾の長音

語尾の長音は省く（例: ディレクトリ、サーバ）。
